PHẦN 1: TỔNG QUAN KIẾN TRÚC TOÀN HỆ THỐNG
----------------------------------------------------------------------------------------------------
Hệ thống gồm 4 phân hệ chính hoạt động độc lập:
1. Backend REST API (apps/api): Cung cấp toàn bộ API quản trị, xác thực, cào dữ liệu Google Drive và quản lý tài khoản.
2. Worker Engine (apps/worker): Xử lý hàng đợi BullMQ chạy nền (Background Queues) cho các tác vụ nặng (Scan file, Export hàng loạt).
3. Frontend Dashboard (apps/web): Giao diện Next.js 16 + React 19 điều hành tập trung toàn bộ kho tài khoản.
4. Thư Viện Dùng Chung (packages/shared): Chứa toàn bộ Mongoose Schemas, Crypto AES-256, Account Parser, Normalizer.

PHẦN 2: CHI TIẾT TỪNG FILE TRONG PACKAGES/SHARED (THƯ VIỆN DÙNG CHUNG)
====================================================================================================

1. packages/shared/src/schemas.ts
   - Chức năng: Định nghĩa toàn bộ Mongoose Schemas và TypeScript Interfaces của hệ thống.
   - Các Schema cốt lõi:
     + AccountSchema (IAccount): Quản lý từng tài khoản MMO.
       * Trường định danh: username, username_normalized.
       * Trường nền tảng: platform ('SHOPEE' | 'TIKTOK' | 'FACEBOOK' | 'MAIL' | 'OTHER').
       * Trường bảo mật mã hóa AES-256: password_enc, cookie_enc, token_enc, session_token, email_password_enc.
       * Trường dàn máy & metadata: machine_id, email, custom_metadata, quality (has_cookie, has_token, has_email).
       * Trạng thái tài nguyên: status ('AVAILABLE' | 'SOLD' | 'USED' | 'ERROR' | 'BLACKLISTED').
       * Lịch sử thao tác: history (IAccountHistory).
       * CHỈ MỤC KÉP QUAN TRỌNG: AccountSchema.index({ platform: 1, username_normalized: 1 }, { unique: true })
         -> Đảm bảo tài khoản Shopee và TikTok cùng tên đăng nhập vẫn tồn tại độc lập 100%, không bao giờ ghi đè lẫn nhau.
     + ScanBatchSchema (IScanBatch): Quản lý từng đợt scan file hoặc Google Sheets Ingress.
     + AuditLogSchema (IAuditLog): Ghi nhật ký kiểm toán toàn bộ thao tác trong hệ thống.
     + ExportJobSchema (IExportJob): Quản lý các lệnh xuất file TXT / XLSX.
     + ApiKeySchema (IApiKey): Quản lý Service API Keys cho tool ngoài.
     + UserSchema (IUser): Quản lý tài khoản nhân viên và phân quyền (OWNER, MANAGER, LEADER, MEMBER).

2. packages/shared/src/crypto.service.ts
   - Chức năng: Mã hóa và giải mã dữ liệu nhạy cảm bằng thuật toán AES-256-GCM chuẩn quân sự.
   - Các hàm chính:
     + encrypt(plainText): Mã hóa chuỗi đầu vào kèm Vector khởi tạo (IV) ngẫu nhiên và Auth Tag.
     + decrypt(cipherText): Giải mã chuỗi về nguyên bản, tự động phát hiện lỗi giả mạo dữ liệu.

3. packages/shared/src/account.parser.ts
   - Chức năng: Bộ não bóc tách dữ liệu tài khoản đa định dạng (Universal Account Parser).
   - Khả năng xử lý:
     + detectPlatform(): Tự động nhận diện nền tảng (SHOPEE, TIKTOK, FACEBOOK, MAIL) dựa trên từ khóa file, tab và nội dung.
     + parseLine(): Bóc tách chuỗi Pipe (User|Pass|Mail|PassMail|Cookie|Token|Machine).
     + parseRow(): Bóc tách từng hàng trong Excel (nhận diện vị trí Email, Password, Cookie ttwid, Cookie Shopee, Mã máy Boxphone M.C542..., p2k1).
     + parseText(): Bóc tách toàn bộ file văn bản nhiều dòng.

4. packages/shared/src/username.normalizer.ts
   - Chức năng: Chuẩn hóa tên đăng nhập về dạng thống nhất (chữ thường, loại bỏ khoảng trắng thừa, ký tự ẩn).
   - Hàm: normalize(raw), isValid(username).

5. packages/shared/src/index.ts
   - Chức năng: Export toàn bộ types, schemas, services của packages/shared cho API và Worker sử dụng.

3. apps/api/src/modules/integrations/google-drive.service.ts
   - Chức năng: Phân hệ Kéo dữ liệu từ Google Drive / Google Sheets chuyên sâu cho Shopee & Tổng thể.
   - Cơ chế cốt lõi:
     + OAuth2 Client tự động nạp client_secret_*.json và google_token.json, tự động làm mới Token khi hết hạn.
     + Vòng lặp phân trang pageToken quét sạch toàn bộ file trên Google Drive & Shared Drives.
     + Bộ lọc nghiêm ngặt !isTikTokFile: Loại trừ 100% tất cả file TikTok ra ngoài để tránh lẫn lộn.
     + Hybrid Stream: Đọc Google Sheets API v4 hoặc stream XLSX qua Drive API v3 để chống tràn RAM và chống lỗi Quota 429.
     + Mã hóa AES-256 toàn bộ mật khẩu, cookie, token trước khi ghi vào MongoDB.
     + Lưu DB theo khóa kép: { platform: 'SHOPEE', username_normalized: parsed.username_normalized }.
     + Auto-Sync Cron: Hẹn giờ tự động quét ngầm mỗi 15p, 30p, 1h, 6h.

4. apps/api/src/modules/integrations/google-drive.controller.ts
   - Chức năng: Cung cấp các REST endpoint cho Google Drive Ingress.
   - Endpoints:
     + GET /api/integrations/google-drive/status: Lấy trạng thái kết nối và tiến trình thời gian thực.

     + POST /api/integrations/google-drive/settings: Bật/tắt tự động quét theo lịch.
     + GET /api/integrations/google-drive/auth-url: Tạo link đăng nhập Google Drive OAuth.

   - Cơ chế cốt lõi:

     + Bộ lọc nghiêm ngặt isTikTokFile: CHỈ quét các file thuộc về TikTok (chứa từ khóa tiktok, 700 acc, farm, boxphone, tt_).

     + POST /api/integrations/tiktok-drive/sync-now: Kích hoạt cào và chuẩn hóa kho TikTok 1-click.

8. apps/api/src/modules/integrations/integrations.module.ts
   - Chức năng: Đăng ký các Controller và Provider của phân hệ tích hợp Drive/Sheets.

9. apps/api/src/modules/backup/backup.service.ts
   - Chức năng: Quản lý bản Snapshot sao lưu dữ liệu và Khóa Bảo Vệ Dữ Liệu Tối Thượng (Fail-Safe Snapshot Guard).
   - Các hàm chính:
     + createSnapshot(): Nén toàn bộ Accounts, ScanBatches, AuditLogs thành file .json.gz lưu vào data/backups/.
     + listBackups(): Lấy danh sách các bản snapshot kèm dung lượng MB và thời gian tạo.
     + restoreSnapshot(): Phục hồi 1-click toàn bộ dữ liệu từ bản snapshot nén.
     + ensurePreDestructiveSnapshot(actionName, actor): KHÓA AN TOÀN BẢO VỆ DỮ LIỆU. Bắt buộc tạo snapshot trước khi thực hiện bất kỳ lệnh xóa/làm sạch nào. Nếu tạo snapshot lỗi -> CHẶN TUYỆT ĐỐI tác vụ ngay lập tức.
     + cleanOldBackups(): Tự động dọn dẹp các bản backup cũ quá 14 ngày.

10. apps/api/src/modules/backup/backup.controller.ts
    - Chức năng: REST Controller cho tính năng Sao lưu & Phục hồi.
    - Endpoints:
      + GET /api/backups: Lấy danh sách snapshot.
      + POST /api/backups/create: Tạo snapshot mới.
      + POST /api/backups/:fileName/restore: Phục hồi dữ liệu từ snapshot.
      + GET /api/backups/:fileName/download: Tải file .json.gz về máy.

11. apps/api/src/modules/backup/backup.module.ts
    - Chức năng: Đăng ký BackupService và BackupController, export BackupService cho các module khác dùng chung.

12. apps/api/src/modules/accounts/accounts.service.ts
    - Chức năng: Xử lý toàn bộ logic nghiệp vụ của Kho Tài Khoản MMO.
    - Các hàm chính:
      + findAll(): Tìm kiếm, lọc đa chiều (platform, status, machine_id, cookie, team, date), phân trang tốc độ cao.
      + getByUsername(): Tra cứu chi tiết 1 tài khoản kèm lịch sử thao tác history đầy đủ.
      + lookupBulk(): Tra cứu hàng loạt danh sách username dán vào.
      + updateStatus(): Đổi trạng thái tài khoản (AVAILABLE, SOLD, USED, ERROR, BLACKLISTED).
      + bulkMarkSold() / bulkMarkUsed() / bulkBlacklist(): Thao tác hàng loạt trên nhiều tài khoản.
      + scanDuplicates(): Quét và gom nhóm các tài khoản bị trùng lặp theo cặp { platform, username_normalized } trong MongoDB.
      + cleanDuplicates(): Tự động hợp nhất và làm sạch bản ghi trùng lặp CÙNG NỀN TẢNG (Tự động kích hoạt ensurePreDestructiveSnapshot trước khi xóa, bảo vệ tuyệt đối không xóa chéo giữa Shopee và TikTok).
      + getStats(): Thống kê số lượng theo nền tảng, trạng thái, dàn máy nuôi.

    - Chức năng: Cung cấp toàn bộ REST API cho Kho Tài Khoản (bảo vệ bởi JwtAuthGuard và RolesGuard).
